## Requirement

Authentication events, privilege changes, access to regulated data and schema changes in tier-0
and tier-1 services emit structured audit records with actor, action, target, timestamp, source
and outcome. Records go to append-only storage (for example S3 Object Lock) with the retention
period set by the regulatory scope.
