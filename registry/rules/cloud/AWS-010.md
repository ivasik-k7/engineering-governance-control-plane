## Requirement

An `aws_lb_listener` (or `aws_alb_listener`) with `protocol = "HTTP"` only redirects to HTTPS
(`default_action { type = "redirect" }`). HTTPS and TLS listeners set `ssl_policy` explicitly,
for example `ELBSecurityPolicy-TLS13-1-2-2021-06`: when it is omitted, listeners created through
the API, CloudFormation or Terraform get `ELBSecurityPolicy-2016-08`, which accepts TLS 1.0 and 1.1.

Explicitly weak policies are reported by SEC-050.
