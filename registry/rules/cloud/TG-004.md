## Requirement

A `dependency` block with `mock_outputs` sets `mock_outputs_allowed_terraform_commands`, and the
list does not include `apply` or `destroy`; `["validate", "plan"]` is the usual value. When the
list is unset, every command may run with mock values, so an `apply` can create resources wired to
placeholder IDs.
