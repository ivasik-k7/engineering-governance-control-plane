## Requirement

The `source` of every `terraform { }` block resolves to an immutable version: Git sources carry
`?ref=` with a tag or commit SHA (not `main`, `master`, `develop`, `dev`, `trunk` or `HEAD`), and
`tfr://` registry sources carry `?version=` or a `version` attribute. Without a version, a `tfr://`
source fetches the latest release. Local paths are fine.

A version supplied through interpolation (`?ref=${local.version}`) counts as pinned; locals from the
same file are resolved, values from included files are not.
