## Requirement

Every `aws_kms_key` with symmetric encryption key material generated by AWS KMS sets
`enable_key_rotation = true` (optionally with `rotation_period_in_days`). Automatic rotation is not
supported for asymmetric keys, HMAC keys or keys in custom key stores, so keys whose
`customer_master_key_spec` is not `SYMMETRIC_DEFAULT`, or that set `custom_key_store_id`, are
exempt; they follow a documented manual rotation procedure.
