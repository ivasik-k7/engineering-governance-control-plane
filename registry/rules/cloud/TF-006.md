## Requirement

Every `provider "aws"` block sets `default_tags { tags = { ... } }` with at least an `owner` and an
`environment` key (any case, e.g. `Owner`, `Environment`), so every taggable resource identifies its
accountable team and environment. Values may come from variables; the keys must be present. Tags
resolved through `local` values and `merge()` are followed within the module.
