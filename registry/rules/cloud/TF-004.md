## Requirement

Terraform writes every resource argument and output to the plan file and to state in clear text,
including values marked `sensitive`; `sensitive = true` only redacts CLI output. Secrets therefore
stay out of state where the provider allows it, and are redacted everywhere else:

- `variable` and `output` blocks whose names denote a secret (password, secret, token, private key,
  API key, access key, credential) set `sensitive = true`, or `ephemeral = true` where the
  Terraform version supports it.
- `aws_db_instance`, `aws_rds_cluster` and `aws_docdb_cluster` use
  `manage_master_user_password = true`, and `aws_redshift_cluster` uses
  `manage_master_password = true`, so the password lives in AWS Secrets Manager. Setting
  `password` or `master_password` stores it in state; the write-only `*_wo` arguments are the
  alternative where a password must be supplied.

State is still treated as secret: encrypted remote backend, restricted read access.
