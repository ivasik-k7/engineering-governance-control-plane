## Requirement

`aws_db_instance`, `aws_rds_cluster_instance`, `aws_redshift_cluster`, `aws_mq_broker` and
`aws_dms_replication_instance` do not set `publicly_accessible = true`.

An `aws_eks_cluster` either sets `vpc_config { endpoint_public_access = false }` or restricts
`public_access_cidrs` to known ranges. The EKS API defaults to a public endpoint open to
`0.0.0.0/0`, so a `vpc_config` that sets neither is reported.
