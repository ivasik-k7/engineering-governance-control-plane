## Requirement

No `*.tfstate`, `*.tfstate.*` (including `.backup`), `*.tfplan`, `tfplan` or `*.tfplan.json` file
is committed. State and saved plans contain every resource attribute in clear text, including
passwords, keys and connection strings. State lives in a remote backend; plan files exist only as
short-lived CI artefacts with restricted access. `.gitignore` excludes these patterns.

A state file that reached a repository is treated as a credential leak: rotate the secrets it
contains, then remove it from history.

The rule applies to every repository, since a state file can be committed where no `.tf` file is.
