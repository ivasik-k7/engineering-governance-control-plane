## Requirement

Every S3 bucket has an `aws_s3_bucket_public_access_block` with all four settings `true`, and
no bucket uses the `public-read` or `public-read-write` canned ACL. Public static content is
served through CloudFront with Origin Access Control.

A waiver is possible only for a documented public website bucket with a data-classification
sign-off.
