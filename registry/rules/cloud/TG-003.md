## Requirement

The root configuration (`root.hcl`, or a file that defines `remote_state` without including
another) sets `terraform_version_constraint` and `terragrunt_version_constraint`, so every unit runs
with a known Terraform or OpenTofu binary and Terragrunt CLI. Units inherit the constraints through
`include`.
