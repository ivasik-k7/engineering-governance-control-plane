## Requirement

Every non-local `module` source resolves to an immutable version:

- registry modules (`namespace/name/provider`, optionally with a hostname) set a `version`
  constraint;
- Git, GitHub and Bitbucket sources carry `?ref=` with a tag or commit SHA, never a branch such as
  `main`, `master`, `develop`, `dev`, `trunk` or `HEAD`;
- S3, GCS and HTTP archives name a versioned object.

Local paths (`./`, `../`) are versioned with the calling code and need no pin. An unpinned source
changes the infrastructure that a reviewed plan describes without any change in this repository.
