## Requirement

Data crossing a trust boundary is parsed into explicit types: JSON into declared classes,
`yaml.safe_load`, Jackson without default typing. `pickle`, `yaml.load` without `SafeLoader`,
Java native serialisation (`ObjectInputStream`), Jackson `activateDefaultTyping` and XStream
without a type allow-list are not used on untrusted input. Internal uses with authenticated,
integrity-protected input need a waiver.
