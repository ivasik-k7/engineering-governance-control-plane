## Requirement

Queries pass user-controlled values as bound parameters. f-strings, `%` formatting, `.format()`
and concatenation must not be used to build SQL passed to `execute()`.

## Compliant

```python
cur.execute("SELECT * FROM users WHERE id = %s", (user_id,))
```

## Non-compliant

```python
cur.execute(f"SELECT * FROM users WHERE id = {user_id}")
```
