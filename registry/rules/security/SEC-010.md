## Requirement

The resolved dependency set must not contain packages with known vulnerabilities of critical
severity. A time-boxed waiver is possible when no fixed version exists and the vulnerable code
path is demonstrably unreachable.

## Rationale

Most exploited vulnerabilities in services are in third-party code, not first-party code.
