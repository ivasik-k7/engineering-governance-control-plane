## Requirement

Staging and production workloads read secrets from AWS Secrets Manager, SSM Parameter Store
(SecureString) or HashiCorp Vault. `.env` files are acceptable only for local development.

## Rationale

A managed store provides audit logging, rotation and revocation; environment files do not.
