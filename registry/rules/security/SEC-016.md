## Requirement

Tokens, one-time passwords, nonces, salts, session and reset identifiers and API keys are
generated with a CSPRNG: `secrets` in Python, `SecureRandom` on the JVM, `crypto/rand` in Go,
`crypto.randomBytes` / `crypto.getRandomValues` in JavaScript. `random`, `java.util.Random`,
`Math.random` and `math/rand` are predictable.
