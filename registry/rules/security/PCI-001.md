## Requirement

Components that handle cardholder data never contain a primary account number (PAN) in source
code, configuration, logs or test fixtures. Tests use the card networks' published test
numbers. Stored PANs are tokenised or encrypted and displayed masked, showing at most the first
six and last four digits (PCI DSS 4.0 requirements 3.3–3.5).

## Rationale

A PAN in a repository brings the repository, its CI system and every clone into PCI DSS scope.
