## Requirement

Source code, configuration files, infrastructure code and test fixtures must not contain
literal credentials: passwords, API keys, tokens, private keys or connection strings with
embedded passwords.

## Rationale

Repository content is copied to laptops, CI caches, forks and AI tool contexts. A committed
secret must be treated as leaked and rotated.

## Compliant

```python
api_key = os.environ["PAYMENTS_API_KEY"]
```

## Non-compliant

```python
api_key = "sk_live_51H8xY2eZvKYlo2C0aBcDeFgH"
```
