## Requirement

Maven, Gradle, Go module and npm dependency sets must not contain packages with known
vulnerabilities rated CVSS 9.0 or higher. Gradle projects commit a dependency lockfile so the
resolved set can be scanned. A time-boxed waiver is possible when no fixed version exists and the
vulnerable code path is demonstrably unreachable.
