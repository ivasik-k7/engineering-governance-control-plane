## Requirement

Every bearer token is validated before use:

- signature, against keys from a trusted JWKS endpoint or key store;
- algorithm, against an explicit allow-list (never `none`);
- `exp` and `nbf`;
- `iss` and `aud` against configured values.

## Rationale

RFC 8725 (JWT Best Current Practices) documents algorithm confusion and missing audience
checks as common, exploitable mistakes.

## Compliant

```python
claims = jwt.decode(token, key, algorithms=["RS256"], audience=AUDIENCE, issuer=ISSUER)
```

## Non-compliant

```python
claims = jwt.decode(token, options={"verify_signature": False})
```
