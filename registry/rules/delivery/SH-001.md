## Requirement

Executable scripts enable `errexit`, `nounset` and, for bash, zsh and ksh, `pipefail` before their
first command, so a failed step, an unset variable or a failed stage of a pipeline stops the script
instead of carrying on with a half-applied change.

```bash
#!/usr/bin/env bash
set -euo pipefail
```

## Validation notes

- Only files with a `#!` line for sh, dash, ash, bash, zsh, ksh or mksh are checked; files without
  one are sourced libraries and inherit the caller's options.
- `set -euo pipefail`, separate `set -e` / `set -u` / `set -o pipefail` lines and the long
  `set -o errexit -o nounset -o pipefail` form are accepted; `set` and `shopt` lines may come in
  any order before the first other command.
- `#!/bin/sh` scripts need `-e` and `-u` only: `pipefail` entered POSIX in the 2024 edition and is
  missing from the dash and BusyBox versions in many base images.
- Options on the shebang line (`#!/bin/bash -e`) do not count; they are lost when the script runs
  as `bash script.sh`.
